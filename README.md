# GitHubPage

## 📌 Sobre o Projeto
Este repositório contém os arquivos de código-fonte de um site desenvolvido como parte de um trabalho acadêmico para a disciplina de **Bootcamp I  ** no curso de **Engenharia de Software** no **UniCeub**.

O objetivo do projeto é **Pode me desenvolver minha habilidades com ferramentas online que sao muito usadas no mundo tech, onde cada vez mais posso evoluir para um dia colocar em pratica as minha habilidades aprendidas nessa materia.**

---

## 🛠️ Desenvolvimento e Tecnologia
O site foi originalmente planejado, estruturado e visualmente construído utilizando a plataforma **Google Sites**. 

Os arquivos presentes neste repositório (`.html`, imagens e scripts associados) representam a exportação/cópia estrutural das páginas criadas na ferramenta para fins de entrega, versionamento e avaliação acadêmica.

* **Versão online (Google Sites):** https://sites.google.com/view/aminhapresentacao/mat%C3%A9rias
